What this module does

DoWaba AI is a connector. It does not change your storefront. It securely exposes your PrestaShop catalog (products, stock, categories, orders) to the DoWaba AI sales platform, so your customers can search, compare and order through WhatsApp, Instagram DM and TikTok. Your data stays in your shop — DoWaba reads it on demand through a signed REST endpoint.

1. Install the module

  1. In PrestaShop admin, open Modules → Module Manager → Upload a module.
  2. Drop dowaba-ai-prestashop-0.2.9.zip. PrestaShop installs and enables it.
  3. Click Configure on the "DoWaba AI" row.

2. Connect — one click

The Configure screen opens with a "Connect to DoWaba in 3 steps" panel at the top.

1 In the settings form, switch Module enabled = ON and Read scope = ON (turn on Write scope too if you want the AI to place orders), then click Save.
2 Click 🔑 Regenerate API Key. The key is shown once (and stored hashed). A green box appears with a "Finish on DoWaba →" button.
3 Click "Finish on DoWaba →". DoWaba opens with your Manifest URL and API Key already filled in (the key travels in the URL fragment, so it is never logged on any server). Log in (or create a free account), pick your store, and click Connect & Import.

Manual alternative: instead of the one-click button, copy the Manifest URL and API Key from the module, then on DoWaba open Integrations → "Connect store" (top of the page), paste both, pick your store and click Connect & Import.

3. How synchronization works & how to verify

DoWaba does not copy your catalog. Synchronization is live and on demand: when a customer asks something on WhatsApp/Instagram/TikTok, the AI calls the matching function on your PrestaShop store in real time and returns the current data — always up to date, nothing stored externally, limited to the scopes you enabled.

Verify it works: after the import (screenshot above), open the connected channel (or the built-in test chat on the DoWaba site) and send "Show me your products" or "Is product X in stock?". The AI replies with real products pulled live from the store.

5. Troubleshooting

SymptomFix
"Manifest could not be fetched"The Manifest URL must be reachable publicly — open it in a browser, it must return JSON. Behind a proxy? Set Manifest base URL override in the module.
"Invalid API key" / 401Regenerate the key in the module and use the fresh one (the old key is replaced on each regenerate).
Import works but no dataTurn ON Module enabled and Read scope, then Save.
403 from the storeAn IP Whitelist is set that excludes DoWaba. Clear it for first setup.
