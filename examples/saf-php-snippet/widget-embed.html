Dowaba Widget — Sayfana Tek Satırla Ekle EXAMPLE

Sitendeki herhangi bir sayfaya, </body> kapanışından hemen önce aşağıdaki <script> tag'ini ekleyince Dowaba destek widget'ı sayfanın sağ alt köşesinde belirir.

1. Anonim (giriş yapmamış ziyaretçi)

<script
    src="https://dowaba.com/widget.js"
    data-destek-key="SENIN_SITE_API_KEY"
    async defer></script>

2. Login'li kullanıcı (HMAC-imzalı token ile)

Login'li kullanıcının kim olduğunu Dowaba'ya bildirmek için, server-side'da dowaba_widget_token() ile imzalanmış bir token üretin ve data-user-token attribute'una basın: 

<?php
require __DIR__.'/lib/dowaba.php';
require __DIR__.'/config.php';

// Login'li kullanıcının bilgileri (örn. session'dan)
$token = dowaba_widget_token([
    'user_id' => $_SESSION['user_id'],
    'email'   => $_SESSION['user_email'],
    'site_id' => DOWABA_WIDGET_SITE_ID,
], DOWABA_WIDGET_SECRET, ttl: 300);
?>

<script
    src="https://dowaba.com/widget.js"
    data-destek-key="<?= htmlspecialchars(DOWABA_WIDGET_SITE_ID) ?>"
    data-user-token="<?= htmlspecialchars($token) ?>"
    async defer></script>

3. Konfigürasyon

data-destek-key: Dowaba admin → site detayı → API Key alanından.
data-user-token: HMAC-imzalı, 5 dakika TTL. Yenilemek için sayfa yenile.
DOWABA_WIDGET_SECRET: Dowaba admin → site detayı → Widget Secret.

Daha fazla örnek: dowaba.com/api-docs-ornekler · GitHub: acr-yazilim/dowaba-plugins
